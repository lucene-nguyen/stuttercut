# Listening checklist (rendered output)

Play each rendered clip once at normal speed, with headphones.

- [ ] No clicks or pops at cut points
- [ ] No clipped first/last syllable around a cut
- [ ] No meaningful word removed (e.g. "à" used as a real word)
- [ ] Lip sync holds after cuts
- [ ] Pauses that remain still sound natural (not too tight)
- [ ] FCP XML (if exported) opens in DaVinci Resolve with cuts in place

Record clip id, result and any timestamp of a problem in the PR or release notes.
